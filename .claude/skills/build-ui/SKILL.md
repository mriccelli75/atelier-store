Build or update customer-facing user interfaces for ecommerce using the existing design system, components, and patterns.
Use when creating or modifying user interfaces, changing pages, sections or customer-facing components.

$ARGUMENTS

1. Inspect the current implementation and related components.
2. Search for reusable components and patterns before creating new ones.
3. Reuse the existing design system, components, and patterns.
4. Implement the requested changes while maintaining consistency with the design system.
5. Test the updated user interface to ensure it works correctly and looks as expected.
6. Review and iterate on the implementation based on feedback and testing results.
7. Ensure accessibility and performance considerations are addressed.
8. Document any new components or patterns for future reuse.
9. Continuously seek opportunities to improve the design system and user interface based on user feedback and best practices.
10. Summarize what changed.
